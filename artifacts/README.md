# Submission artifact bundle

This folder contains the generated fictional Affidavit in Reply and the evaluation report requested for the demonstration submission.

- `affidavit-in-reply-demo.docx`: generated editable Word document.
- `evaluation-report.md`: generation inputs, hash, and verification results.

All names, case details, dates, and statements are fictional demonstration data. The document is not approved for filing and is not legal advice.
